# Приложение для анализа тренировок

Система классификации типов тренировок на основе данных о физической активности

---

#### Для запуска необходимо:

1. Запустить [проект](https://github.com/VadimBarinov/catboost-api)

2. Запустить этот проект

```
docker compose up --build
```

#### Приложение будет доступно по адресу:

```
http://localhost:8000/strava-activity/
```
